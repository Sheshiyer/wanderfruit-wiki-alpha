## Email Automation Rules

**Welcome Sequence Triggers:**
- Email 1A: Newsletter signup → Send immediately
- Email 1B: Signup + 48hrs + no booking → Send day 3

**Booking Sequence Triggers:**
- Email 2A: Booking confirmed → Send immediately
- Email 2B: 48hrs before checkin → Send exactly 48hrs pre-arrival
- Email 2C: 24hrs after checkout → Send next day

**Recovery Sequence Triggers:**
- Email 3A: 3+ properties viewed + 24hrs + no booking → Send next day

**Suppression Rules:**
- If booking made → suppress all recovery emails
- If unsubscribed → suppress all marketing, keep transactional only
- If stay is in-progress → suppress marketing, allow booking-related only
